保存或更新运营配置
  POST /app-api/play/config/save
请求:
{
  "id": 0,			主键ID,不传或为null则为新增
  "configKey": "",	配置键
  "refId": "",		关联标识：学校ID/年级名称/班级ID；全局配置可不传
  "refType": 0,		关联类型：0=全局，1=学校，2=年级，3=班级
  "value": "",		普通配置内容：字符串或文本
  "valueJson": "",	JSON 配置内容
  "enableStatus": 0	启用状态：0=启用，1=禁用
}
返回:
{
	"code": 0,
	"msg": "",
	"data": true
}
